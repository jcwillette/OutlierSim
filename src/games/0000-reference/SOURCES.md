# Sources: Reference Game (engine test)

This game is **fictional** and models no FRC season, so there is no manual to cite. It exists to exercise every engine feature: shooting with recycling, placing on two levels, a `direct` and a `drop` human player station, an endgame with per-zone limits, leave and park awards, two bonus RPs, and a `rules.ts` mechanic (Overdrive).

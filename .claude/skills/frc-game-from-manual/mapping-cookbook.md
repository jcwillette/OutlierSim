# Mapping FRC mechanics onto the engine

Schema: `src/engine/sim/types.ts`. Example of every pattern: `src/games/0000-reference/`.
When a mechanic doesn't fit any of these, use `rules.ts`. If even that can't express it, record it as a simplification and add it to `docs/ROADMAP.md` (Known gaps).

| Real mechanic                                                                 | How to model it                                                                                                                                                                                                                                                                                                                             |
| ----------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Goal you shoot into from range (hub, speaker, high goal)                      | `ScoringTarget` with `aperture` (box at the opening, `entry: 'down'` for top-entry goals), `aimPoint` at the opening's center. Archetypes need a `shooter`. The solid structure is a separate `FieldElement`.                                                                                                                               |
| Low goal or slot you drive up to and drop or place into                       | `ScoringTarget` with `place.zone` (where the robot's center must be) and `facePoint` (what the front must face). Add a `tags` entry such as `'low'` and give archetypes `place: { low: secs }`.                                                                                                                                             |
| Multi-level structure (grid rows, reef levels, shelves)                       | One target per level, all sharing the same `place.zone`, with tags `L1`…`L4`. Points and capacity per level. Archetypes list the levels they can reach, slower for higher levels.                                                                                                                                                           |
| Grid of individual nodes where adjacency matters (links, rows)                | One target per node with `capacity: 1`, a narrow `place.zone` per column and a `display` point so scored pieces are drawn in place. Compute adjacency bonuses from `targetCounts` in `rules.ts` / a custom RP (see `2023-chargedup/layout.ts`).                                                                                             |
| Goal accepting both shots and placement                                       | One target with both `aperture` and `place`.                                                                                                                                                                                                                                                                                                |
| Pieces that return to play after scoring (hub feeds back out, cargo returns)  | `afterScore: { kind: 'recycle', delaySec, exits, exitVelocity }`.                                                                                                                                                                                                                                                                           |
| Pieces that leave play after scoring                                          | Default `consume`.                                                                                                                                                                                                                                                                                                                          |
| Human player hands pieces to robots at a station                              | `HumanPlayerStation` with `mode: 'direct'` and a `feedIntervalSec` from realistic HP speed (1-2 s).                                                                                                                                                                                                                                         |
| HP shelf the robot has to reach up to and line up on (double substation)      | `mode: 'direct'` plus `handoffHeight` (only robots whose `intake.maxHeight` reaches it) and `handoffSec` (time to line up and grab). To let players choose the piece type, make one station per type with its own zone.                                                                                                                     |
| Human player drops or rolls pieces through a chute, or onto the floor         | `mode: 'drop'` with `dropPoint` and `dropVelocity`.                                                                                                                                                                                                                                                                                         |
| Human player throws pieces into a goal                                        | `rules.ts` `onTick`: on a timer, `ctx.spawnPiece` with a velocity aimed at the target. Model it as a probability per attempt, and keep it simple.                                                                                                                                                                                           |
| Limited pieces at stations                                                    | `supply` per alliance.                                                                                                                                                                                                                                                                                                                      |
| Auto "leave the starting zone" points                                         | `PositionAward` `kind: 'leaveZoneInAuto'`.                                                                                                                                                                                                                                                                                                  |
| Park in a zone at match end                                                   | `PositionAward` `kind: 'inZoneAtEnd'` (not awarded if the robot did an endgame action).                                                                                                                                                                                                                                                     |
| Climb / hang / dock                                                           | `EndgameAction` with `zones` (one per bar, cage or position), `maxRobotsPerZone`, and `points`. Archetypes list `endgame: { id: secs }`. Make a separate action per climb level, all with the same zones. Bots pick the most valuable one they can do.                                                                                      |
| Endgame on a shared platform robots board one by one (charge station)         | `oneAtATime: true` on its actions: a robot can't start while a teammate is mid-action. Bots plan for the queue. Use one zone (slot) per robot so bots spread out.                                                                                                                                                                           |
| Endgame action in auto that the robot leaves afterwards (auto dock)           | `allowInAuto`, `autoPoints`, `availableAtRemainingSec: -1` for an auto-only action. The robot is released when teleop starts; bots plan it near the end of auto. Per-alliance auto limits go in `rules.ts`.                                                                                                                                 |
| Climb allowed in auto                                                         | `allowInAuto: true` and `autoPoints`.                                                                                                                                                                                                                                                                                                       |
| Bonus for several robots climbing together (harmony, coopertition)            | `rules.ts` `onMatchEnd`: count `ctx.robots()` with an `endgameAction` and call `ctx.addPoints`, or use a custom RP.                                                                                                                                                                                                                         |
| RP for N pieces scored                                                        | `rankingPoints.bonuses` `kind: 'piecesAtLeast'` with `tags` or `targetIds`.                                                                                                                                                                                                                                                                 |
| RP for endgame points                                                         | `kind: 'endgamePointsAtLeast'`.                                                                                                                                                                                                                                                                                                             |
| RP with complex criteria (per-level counts, coopertition lowering thresholds) | `kind: 'custom'`, with `check(own, opp)` over the alliance summaries (`targetCounts`, `endgame`, `breakdown`).                                                                                                                                                                                                                              |
| Temporary scoring multiplier (amplify)                                        | `rules.ts`: track the trigger in `onScore`, call `ctx.setTargetMultiplier(id, k)`, reset it in `onTick`, and show it with `setIndicator`.                                                                                                                                                                                                   |
| Element active or inactive on a schedule (hub shifts)                         | `rules.ts` `onTick`: `ctx.setTargetEnabled(id, bool)` by `ctx.time` or `ctx.phase`, plus an indicator and `announce`.                                                                                                                                                                                                                       |
| Points awarded to the alliance whose robot did it, at a neutral element       | `side: 'neutral'`, `creditTo: 'scorer'`. Credit goes to the last robot to touch the piece.                                                                                                                                                                                                                                                  |
| Opponent-side scoring (scoring in the opponent's structure)                   | A sided target with `creditTo: 'scorer'`.                                                                                                                                                                                                                                                                                                   |
| Protected zones and contact fouls (bot side)                                  | List the zone base ids in `botHints.protectedZones` (always) and `botHints.endgameProtectedZones` (endgame only, e.g. a climb area). Bots then don't defend in or near them, don't fetch loose pieces from them, and path around them when they can. Pinning: see the G202 check in `2023-chargedup/rules.ts` (uses `RobotInfo.cmdX/cmdY`). |
| Protected zones and contact fouls                                             | Not detected by the engine yet. If the game depends on them, detect a simple version in `rules.ts` `onTick` (an opponent robot inside the zone touching a defender) and call `ctx.foul`. Otherwise list it as a simplification.                                                                                                             |
| Ramps and charge stations                                                     | `hull` elements. Low ramps (under 0.2 m) are drivable for the bots' navigation; add >= 0.2 m guard boxes on sides robots can't climb so bots path over the ramps. Tilting isn't simulated: model docking/balancing as `EndgameAction`s and decide LEVEL in `rules.ts` (see `2023-chargedup`).                                               |
| Elements robots drive under                                                   | Solid legs plus a non-solid (`solid: false`) visual top, or a top whose bottom is higher than robot height.                                                                                                                                                                                                                                 |
| Pieces stacked or stored in a robot                                           | `capacity` per type and `totalCapacity`.                                                                                                                                                                                                                                                                                                    |
| Game-specific robot limits (one piece at a time)                              | Set `capacity` and `totalCapacity` accordingly.                                                                                                                                                                                                                                                                                             |

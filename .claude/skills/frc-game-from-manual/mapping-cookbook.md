# Mapping FRC mechanics onto the engine

Schema: `src/engine/sim/types.ts`. Example of every pattern: `src/games/0000-reference/`.
When a mechanic doesn't fit any of these, use `rules.ts`. If even that can't express it, record it as a simplification and add it to `docs/ROADMAP.md` (Known gaps).

| Real mechanic                                                                                             | How to model it                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| --------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Goal you shoot into from range (hub, speaker, high goal)                                                  | `ScoringTarget` with `aperture` (box at the opening, `entry: 'down'` for top-entry goals), `aimPoint` at the opening's center. Archetypes need a `shooter`. The solid structure is a separate `FieldElement`. A mouth that opens downward under a hood (2024 SPEAKER): `arc: 'rising'` (the fastest shot still rising at the aim point) and a solid hood element; hood ranges (`pitchRangeDeg`) set where each robot can shoot from.                                                                                                                                                                                                     |
| Low goal or slot you drive up to and drop or place into                                                   | `ScoringTarget` with `place.zone` (where the robot's center must be) and `facePoint` (what the front must face). Add a `tags` entry such as `'low'` and give archetypes `place: { low: secs }`.                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Multi-level structure (grid rows, reef levels, shelves)                                                   | One target per level, all sharing the same `place.zone`, with tags `L1`…`L4`. Points and capacity per level. Archetypes list the levels they can reach, slower for higher levels.                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Grid of individual nodes where adjacency matters (links, rows)                                            | One target per node with `capacity: 1`, a narrow `place.zone` per column and a `display` point so scored pieces are drawn in place. Compute adjacency bonuses from `targetCounts` in `rules.ts` / a custom RP (see `2023-chargedup/layout.ts`).                                                                                                                                                                                                                                                                                                                                                                                          |
| Goal accepting both shots and placement                                                                   | One target with both `aperture` and `place`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| Pieces that return to play after scoring (hub feeds back out, cargo returns)                              | `afterScore: { kind: 'recycle', delaySec, exits, exitVelocity }`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Pieces that leave play after scoring                                                                      | Default `consume`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Human player hands pieces to robots at a station                                                          | `HumanPlayerStation` with `mode: 'direct'` and a `feedIntervalSec` from realistic HP speed (1-2 s). The robot then stops for its own `intake.timeSec` to grab the piece.                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| HP shelf the robot has to reach up to and line up on (double substation)                                  | `mode: 'direct'` plus `handoffHeight` (only robots whose `intake.maxHeight` reaches it) and `handoffSec` (time to line up and grab). If the human player can hand out either piece, set `choice: true`: players pick with F / gamepad X and bots ask for the piece they plan to score.                                                                                                                                                                                                                                                                                                                                                   |
| Human player drops or rolls pieces through a chute, or onto the floor                                     | `mode: 'drop'` with `dropPoint` and `dropVelocity`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| Human player throws pieces into a goal                                                                    | `rules.ts` `onTick`: on a timer, `ctx.spawnPiece` with a velocity aimed at the target. Model it as a probability per attempt, and keep it simple.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Limited pieces at stations                                                                                | `supply` per alliance.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Auto "leave the starting zone" points                                                                     | `PositionAward` `kind: 'leaveZoneInAuto'`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| Park in a zone at match end                                                                               | `PositionAward` `kind: 'inZoneAtEnd'` (not awarded if the robot did an endgame action).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Climb / hang / dock                                                                                       | `EndgameAction` with `zones` (one per bar, cage or position), `maxRobotsPerZone`, and `points`. Archetypes list `endgame: { id: secs }`. Make a separate action per climb level, all with the same zones. Bots pick the most valuable one they can do.                                                                                                                                                                                                                                                                                                                                                                                   |
| Endgame on a shared platform robots board one by one (charge station)                                     | `oneAtATime: true` on its actions: a robot can't start while a teammate is mid-action. Bots plan for the queue. Use one zone (slot) per robot so bots spread out.                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Endgame action in auto that the robot leaves afterwards (auto dock)                                       | `allowInAuto`, `autoPoints`, `availableAtRemainingSec: -1` for an auto-only action. The robot is released when teleop starts; bots plan it near the end of auto. Per-alliance auto limits go in `rules.ts`.                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Climb allowed in auto                                                                                     | `allowInAuto: true` and `autoPoints`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Bonus for several robots climbing together (harmony, coopertition)                                        | `rules.ts` `onMatchEnd`: count `ctx.robots()` with an `endgameAction` and call `ctx.addPoints`, or use a custom RP.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| RP for N pieces scored                                                                                    | `rankingPoints.bonuses` `kind: 'piecesAtLeast'` with `tags` or `targetIds`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| RP for endgame points                                                                                     | `kind: 'endgamePointsAtLeast'`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| RP for points from some sources (charge station, stage, barge, incl. auto)                                | `kind: 'pointsAtLeast'` with `sources` (target / endgame action / award base ids and the source names `rules.ts` passes to `addPoints`) and optionally `categories`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| RP with complex criteria (per-level counts, coopertition lowering thresholds)                             | `kind: 'custom'`, with `check(own, opp)` over the alliance summaries (`targetCounts`, `endgame`, `breakdown`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Temporary scoring multiplier (amplify)                                                                    | `rules.ts`: track the trigger in `onScore`, call `ctx.setTargetMultiplier(id, k)`, reset it in `onTick`, and show it with `setIndicator`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Drive teams holding a shot for a multiplier (wait for the AMPLIFY press)                                  | `rules.ts` `botHold(ctx, alliance, targetId)`: true while a ready shot is about to be worth more (2024: a full AMP bank). Bots hold at most 14 s per arrival. Pair it with when the human player triggers the multiplier (2024: once two robots have a piece).                                                                                                                                                                                                                                                                                                                                                                           |
| Passing / feeding (lobbing pieces to a teammate's side)                                                   | `GameDefinition.passing`: `landing` spots (blue's frame) near the goal, `notFromOpponent` zone base ids (2024 G414: the opponent's WING), `minDistance`. Archetypes that pass get `shooter.passRange`. Bots pass only with a specialist role that has `feeds: true`.                                                                                                                                                                                                                                                                                                                                                                     |
| Defense at the opponents' loading area (a choke point)                                                    | A specialist role with `defense: 'source'`, besides the built-in goal-side `defense`. Name it in lineups like any role.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Structure short robots drive under and tall ones can't (2024 STAGE)                                       | The structure with `nav: 'none'` and `clearance` (its underside height). Taller archetypes get their own nav grid that treats it as a wall; physics already blocks them.                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| A zone that is protected only late in the match but useful to drive through before (2024 STAGE ZONE)      | `botHints.endgamePathZones` (bots path around it only from 5 s before the endgame), not `protectedZones` (all match). Declare the foul `endgameOnly`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| A robot that loads only from a human player (2024 KitBot)                                                 | `intake: { ..., floor: false }`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| Robot types that aren't equally common (two builds of one tier, a defense-only robot)                     | `RobotArchetype.dealWeight` (default 1; 0 = never dealt by the random preset, still in the menu and lineups).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Element active or inactive on a schedule (hub shifts)                                                     | `rules.ts` `onTick`: `ctx.setTargetEnabled(id, bool)` by `ctx.time` or `ctx.phase`, plus an indicator and `announce`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Points awarded to the alliance whose robot did it, at a neutral element                                   | `side: 'neutral'`, `creditTo: 'scorer'`. Credit goes to the last robot to touch the piece.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| Opponent-side scoring (scoring in the opponent's structure)                                               | A sided target with `creditTo: 'scorer'`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Protected zones with contact fouls (loading zones, community, a protected climb area)                     | Declare them: `fouls.contact` rules with the zone base ids, `inside: 'intruder'` (the opponent is in the zone, e.g. 2023 G207), `'protected'` (the protected robot is) or `'either'` (2024 G423: "any part of either ROBOT"), `fully` if the manual says "completely within", `endgameOnly`, severity and `repeatSec` ("per instance"). The engine calls them on bumper contact (`src/engine/sim/referee.ts`). Bots read the same zones (`botHints.protectedZones` / `endgameProtectedZones` only to override).                                                                                                                          |
| Pinning ("5-count on PINS")                                                                               | `fouls.pinning`: `countSec`, first and repeat severity, `releaseGap` (usually 6 ft: the robots that far apart, or either that far from where the pin started, ends it; so does the pinning robot getting pinned) and `repinSec` (pinning again sooner resumes the count, usually 3 s). Bots break off pins themselves (3 s) and back off past the release gap.                                                                                                                                                                                                                                                                           |
| A penalty that awards points instead of a foul (2023 G209: touched robots count as ENGAGED)               | Not a `fouls` rule. Give the bots the zone as `botHints.endgameProtectedZones` so they stay clean, and list the penalty under Simplifications (or award it in `rules.ts` if it matters).                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Ramps, platforms and charge stations                                                                      | A sloped `hull` at the manual's height with `nav: 'ramp'`: bots drive over it slowly, and in physics its floor edges continue 3 cm below the floor so the box-shaped robots drive up from any speed (without that they stall at the base unless they hit it fast). Give guards or edges robots can't climb `nav: 'wall'`. A `box` with vertical sides is a step, not a ramp. Test it like `tests/chargedup.test.ts` ("drives onto the Charge Station from a slow approach", every robot type). Tilting isn't simulated: model docking/balancing as `EndgameAction`s and decide LEVEL in `rules.ts` (see `2023-chargedup`).               |
| Elements robots drive under                                                                               | Solid legs plus a non-solid (`solid: false`) visual top, or a top whose bottom is higher than robot height.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| A penalty that also awards the opponent an RP (2024 G424: the ENSEMBLE RP)                                | Declare the foul; the RP's `custom` check reads `opp.foulCalls` (keys are `<rule id> <name>`). Two TECH FOULS per contact: two rules with the same zones.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Robot drive speed, acceleration, weight                                                                   | `driveFor(swerve(motor, gearing, robotLb, { tipping }), maxOmega)` / `tank(...)` and `onFieldMass(robotLb)` from `src/engine/sim/drivetrain.ts`. These turn COTS hardware (vendor motor curves, SDS / REV / Kit of Parts ratios) into the engine's constant-acceleration model, with current limits, traction and tipping. Cite the hardware in `SOURCES.md`.                                                                                                                                                                                                                                                                            |
| Manual units, regions and citations                                                                       | `src/engine/sim/authoring.ts`: `IN`, `FT`, `LB`, `DEG`, `feet(ft, in)`, `rect`, `poly`, `circle`, `cite('Manual')` (then `M(47, 'Table 6-2')`). Keep the manual's own figures visible in the expression.                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Per-alliance limits on auto actions ("1 ROBOT max")                                                       | `rules.ts` `onPhaseChange('teleop')`: keep the best one and take back the rest with negative `addPoints` (2023's `auto-charge-limit`). Add the source to any `pointsAtLeast` RP that counts the action.                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Per-tick game state in `rules.ts` (links, completed grids, indicators)                                    | Recompute only when something changed: set a flag in `onScore`, act on it in `onTick` (same tick, so results don't move). Take one `ctx.robots()` snapshot per tick. Never prefer a fixed direction or alliance order (ADR 0007).                                                                                                                                                                                                                                                                                                                                                                                                        |
| Pieces stacked or stored in a robot                                                                       | `capacity` per type and `totalCapacity`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Game-specific robot limits (one piece at a time)                                                          | Set `capacity` and `totalCapacity` accordingly.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| A robot's autonomous routine (pieces it scores, leaving the start zone, how often it works)               | `RobotArchetype.auto: { pieces, leave, success }`. Bots follow it in auto (the player's "auto routine" option too, which always runs). Most real robots score one preload or nothing; take the tier values from `robot-baselines.md`. Omit it and the bot does the planner's best auto. Robots whose routine doesn't run but still drive forward (no piece scored): `driveOut`, the chance of that (2025: 72-92 % by tier, needed for an all-robots LEAVE RP).                                                                                                                                                                           |
| How long a real drive team takes to line up a pickup or a placement (misses and retries included)         | `RobotArchetype.alignSec`, added to teleop pickups and placements only. Programmed autos don't pay it, the student's own robot doesn't either (`MatchOptions.alignExempt`), and the bot difficulty scales it (`SKILL.align`). Tier values (2023-calibrated) are in `robot-baselines.md`. A target much wider or more precise than the rest scales it for placements there with `ScoringTarget.alignScale` (2025: the trough 0.9, L4 1.2).                                                                                                                                                                                                |
| An endgame attempt that sometimes fails (balance, climb)                                                  | `RobotArchetype.endgameSuccess` per action, plus the action's `fallback` (2023: a failed engage still docks). Without a fallback the robot tries again while there's time.                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| Set bonuses real teams build on purpose (links, combos, a shared RP threshold)                            | `rules.ts` `botValue(ctx, alliance, targetId)`: the extra points bots should count for a target right now, e.g. the link it would complete (2023). Bots only; the score never changes. Switch the push off when the alliance can't finish the bonus in the time left (2025's CORAL RP: 0.2 pieces per second per alliance). A bonus both alliances must work for (Coopertition) is agreed per match: roll it in `onInit` (2025: both 15 %, else each alone 15 %).                                                                                                                                                                        |
| A piece resting on a field structure that robots take (2025 REEF ALGAE), and targets it blocks until then | A `HumanPlayerStation` with `supply: 1`, `handoffHeight` at the piece's center, `display` (drawn until taken), `auto: true` if robots take it in AUTO and `lane: false` (not a loading area). `rules.ts` disables the blocked targets in `onInit` and re-enables them when `ctx.stationUsed(id, alliance)` turns 1. Add `knockOff: true` when robots may knock it to the floor instead (most 2025 REEF ALGAE went that way), and give `rules.ts` a `botStationValue` for what clearing it opens. A `knockOff` station's piece goes only to a bot loading from it (`RobotCommand.loadFrom`), so bots scoring beside it don't sweep it up. |
| "No more than 1 ROBOT on the opponent's side" (2025 G421)                                                 | Call it in `rules.ts` `onTick` from `ctx.robots()`, and give the bots `botHints.oneAcrossLine` so they keep to it.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| A goal that passes the piece to the opponent's human player, who throws it (2025 PROCESSOR → NET)         | `rules.ts`: count it in `onScore`, then `ctx.spawnPiece` a ballistic throw at the opponent's goal on a timer (TELEOP only if the rules say so); a fixed hit chance picks the aim, and misses land where they can't pass through the goal. Give the bots its net worth in `botValue` (its points minus the opponent's expected points: 2025 real HUMAN PLAYERS netted 86 %).                                                                                                                                                                                                                                                              |
| Scored pieces drawn side by side or tilted (a trough, angled branches)                                    | `ScoringTarget.displayStep` and `displayRotation`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |

# 0001: 3D with Three.js, TypeScript, Vite, and a static site on GitHub Pages

- Status: accepted
- Date: 2026-11-23

## Context

Students should get the _feel_ of a new FRC game within days of kickoff, similar to frsim.com. The owner chose 3D over 2D top-down. Games are generated by Claude from a manual, so mistakes in generated code need to be caught before students see them.

## Decision

- Render with Three.js. Ship as a static Vite build deployed to GitHub Pages, so there is no server and nothing to install.
- Write everything in TypeScript with `strict` on. Generated game modules are type-checked against `GameDefinition`.

## Consequences

- A build step is needed. CI runs lint, typecheck, test and build on every PR.
- The 3D view is costly on weak school laptops, so the renderer has to stay primitive-based and low-poly.
